# Code of conduct

Be respectful, constructive, and specific. Harassment, discrimination, threats, doxxing, sexual
attention, and sustained disruption are not acceptable in project spaces.

Assume good intent while discussing ideas, but listen when impact is raised. Critique code and
decisions, not people. Protect private data encountered in bug reports and development.

Maintainers may edit or remove harmful content and may temporarily or permanently restrict
participation. Report conduct concerns through a private maintainer channel when one is available;
otherwise request private contact in a minimal public message without repeating sensitive details.
